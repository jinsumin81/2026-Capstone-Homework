# PART 4. ChatGPT 앱과 나만의 맞춤형 GPT 만들기

## 1. ChatGPT 앱 활용

### ChatGPT 데스크탑 앱 특징
- 브라우저 없이 실행 가능한 독립형 앱
- Alt + Tab 전환 등 멀티태스킹 지원
- 단축키, 다크모드, 알림 기능 제공
- 브라우저보다 메모리 사용 감소 및 안정적 실행

### ChatGPT 앱 설치 방법
- OpenAI 공식 사이트 또는 Microsoft Store에서 설치 가능
- “chatgpt app download” 검색 후 다운로드
- 설치 파일 : ChatGPT Installer.exe

### ChatGPT 앱 실행
- 로그인 후 사용
- 웹 버전과 유사한 인터페이스 제공
- 워크스페이스 선택 가능

# 2. 맞춤형 GPT 만들기

## 맞춤형 GPT 개요
- 사용 목적에 맞게 GPT를 개인화 가능
- 전문 분야, 성격, 스타일 설정 가능
- 프로그래밍 지식 없이 제작 가능
- 학습 튜터, 고객 상담, 개인 비서 등 다양한 활용 가능

### 특징
- 응답 길이 조절 가능
- 대화 톤 설정 가능
- 특정 주제 범위 지정 가능
- 생산성 향상에 도움

※ 맞춤형 GPT 기능은 유료 사용자 기능

# 3. ‘내 GPT’ 만들기

## 기본 제작 과정
1. 프로필 → “내 GPT” 선택
2. “만들기” 버튼 클릭
3. GPT의 역할과 목적 작성
4. 이름, 설명, 지침 설정
5. 테스트 후 수정

### 역할 설정 예시
- “대학생을 위한 컴퓨터 과학 발표 자료 제작 튜터”

# PART 5. ChatGPT 프로젝트로 전문가 되기

# 1. ChatGPT 프로젝트 개요

## 프로젝트란?
- 하나의 목표를 중심으로 작업을 관리하는 기능
- 자료, 파일, 지침 등을 체계적으로 관리 가능

## 활용 분야
- 보고서 작성
- 팀 과제
- 연구 프로젝트
- 취미 계획

## 장점
- 복잡한 작업 정리 가능
- 단계별 진행 가능
- 효율적인 작업 관리 가능

---

# 2. ChatGPT 프로젝트 활용 분야

## 아이디어 발전
- 브레인스토밍 지원
- 새로운 관점 제시

## 콘텐츠 제작
- 블로그, 시, 소설 작성 가능
- 문장 구조 개선 가능

## 학습 및 연구
- 학습 효율 향상
- 이해하기 쉬운 설명 제공

## 문제 해결
- 단계별 해결 과정 제시
- 다양한 해결 방법 제안

---

# 3. 프로젝트 구성

## 프로젝트 생성 방법
1. 왼쪽 메뉴에서 “프로젝트” 선택
2. “+ 새 프로젝트” 클릭
3. 원하는 주제로 생성

## 구성 요소
- 파일 추가
- 채팅 관리
- 지침 작성

※ 현재는 “지침 추가” 기능 대신 직접 질의로 작성

---

# 4. 프로젝트 활용 사례

## 보고서 작성 프로젝트 예시
주제 :
- 기후 변화와 청년 세대

### 보고서 구성
- 서론 : 기후 위기의 심각성
- 본론 : 청년의 인식과 참여 사례
- 결론 : 실천 유도 방안

### 작성 방식
- 파일 첨부 후 질의
- 목차 구조 지정 가능
- A4 5~6페이지 분량 설정 가능
