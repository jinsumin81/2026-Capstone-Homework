## ✅ 정답 및 풀이

**[이론 1] 정답: (B) ②④**

풀이:
1. **immutable**이란 생성 후 내용을 변경할 수 없는 객체를 의미합니다.
2. `tuple`(②)은 생성 후 요소 추가·삭제·변경이 불가능 → immutable ✅
3. `str`(④)은 문자열 자체를 수정할 수 없고, 새 문자열이 생성됨 → immutable ✅
4. `list`(①), `dict`(③), `set`(⑤)는 요소를 자유롭게 추가·삭제·변경 가능 → mutable ❌
5. **팁**: immutable 객체는 딕셔너리의 **키(key)** 로 사용할 수 있습니다. 리스트는 불가.

---

**[이론 2] 정답: (B) 10**

풀이:
1. 파이썬에서 함수 내부에 선언된 변수는 **지역 스코프(local scope)** 에 속합니다.
2. `foo()` 안의 `x = 99`는 **새로운 지역 변수** `x`를 만들 뿐, 전역 변수 `x`에 영향을 주지 않습니다.
3. 함수가 종료되면 지역 변수는 소멸됩니다.
4. 따라서 `print(x)`는 전역 `x = 10`을 출력합니다.
5. **만약 전역 변수를 수정하려면?** 함수 내에서 `global x`를 먼저 선언해야 합니다.

---

**[이론 3] 정답: (B) `[1, 4, 7]`**

풀이:
1. `range(start, stop, step)` — start부터 시작해 step씩 증가, stop **미만**까지 생성합니다.
2. `range(1, 10, 3)` → 1, 1+3=4, 4+3=7, 7+3=10 (10은 stop이므로 제외)
3. 결과: `1, 4, 7`
4. (C)의 10은 stop 값이라 포함되지 않으므로 오답입니다.

**[심화 1] 정답: `[1, 9, 25]`**

풀이:
1. 리스트 컴프리헨션 `[x**2 for x in data if x % 2 != 0]`을 분해합니다.
2. **필터 조건** `x % 2 != 0`: 홀수인 원소만 선택 → `1, 3, 5`
3. **변환** `x ** 2`: 각 원소를 제곱 → `1**2=1`, `3**2=9`, `5**2=25`
4. 최종 결과: `[1, 9, 25]`

**[심화 2] 정답 (수정된 코드)**

```python
def calculate_average(numbers):
    total = 0
    for n in numbers:
        total += n                      # 수정 1: =+ → +=
    return total / len(numbers)

scores = [80, 90, 70]
print(calculate_average(scores))       # 수정 2: 인수 scores 추가
```

풀이:
1. **버그 1**: `=+`는 "양수 부호 연산자를 적용해 대입"하는 것으로, `total = (+n)`과 동일합니다. 누적 합산이 안 되고 `total`은 항상 마지막 `n` 값만 가집니다. 올바른 복합 대입 연산자는 `+=`입니다.
2. **버그 2**: `calculate_average()`를 인수 없이 호출하면 `TypeError`가 발생합니다. `numbers` 매개변수에 `scores`를 전달해야 합니다.

**[심화 3] 정답**

- 빈칸 A: `d`
- 빈칸 B: `max_val`
- 빈칸 C: `key`

풀이:
1. `.items()`는 딕셔너리를 `(key, value)` 쌍의 이터러블로 반환합니다. 순회 대상은 딕셔너리 `d` 자체여야 하므로 빈칸 A = `d`.
2. 현재까지의 최댓값(`max_val`)과 비교해야 하므로 빈칸 B = `max_val`.
3. 최댓값 갱신 시 해당 키를 저장해야 하므로 빈칸 C = `key`.
4. `float('-inf')`는 어떤 수와 비교해도 항상 작으므로, 첫 비교에서 반드시 갱신이 일어나도록 하는 초기화 기법입니다.

**[심화 4] 정답**

```python
def flatten(nested):
    return [item for sublist in nested for item in sublist]
```

풀이:
1. 이중 `for`를 한 줄 컴프리헨션으로 표현합니다.
2. 읽는 순서: "각 `sublist`를 `nested`에서 꺼내고, 그 `sublist` 안의 각 `item`을 수집한다."
3. 일반 루프로 풀면:
```python
result = []
for sublist in nested:
    for item in sublist:
        result.append(item)
```
4. 이것을 한 줄 컴프리헨션으로 압축한 것이 정답입니다.
