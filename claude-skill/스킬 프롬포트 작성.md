[문제 2] 정답: (a) O / (b) X

📝 해설:

(a) O: 기본값(default value)이 지정된 매개변수는 호출 시 생략 가능합니다. 생략하면 지정된 기본값이 사용됩니다.
(b) X: 반대입니다. 기본값이 없는 매개변수가 앞에, 기본값이 있는 매개변수가 뒤에 와야 합니다. 그렇지 않으면 SyntaxError가 발생합니다.

# ✅ 올바른 순서: 기본값 없는 것 → 기본값 있는 것
def func(a, b=10):
    pass

# ❌ 잘못된 순서
def func(a=10, b):  # SyntaxError!
    pass

python
def add(a, b):
    return a + b      # ✅ 값을 반환

def add_wrong(a, b):
    print(a + b)      # ❌ 화면에 출력만 할 뿐, 반환값은 None

result = add(3, 5)
print(result)  # 8

result2 = add_wrong(3, 5)  # 8 출력됨

python
# 위치 인자: 순서가 중요

[문제 5] 정답: None / 이유: say_hello()는 return문이 없기 때문에 자동으로 None을 반환한다.

📝 해설: 파이썬의 모든 함수는 반드시 값을 반환합니다. return문을 명시하지 않으면 파이썬이 자동으로 return None을 실행합니다. print()는 화면에 출력하는 동작이지, 값을 반환하는 것이 아닙니다. 이 둘을 구분하는 것은 함수 학습에서 가장 중요한 포인트 중 하나입니다.

python
def say_hello():
    print("Hello!")
    # 내부적으로 return None이 자동 추가됨

result = say_hello()  # "Hello!" 출력
print(result)         # None 출력

# 비교: return이 있는 경우
def get_hello():
    return "Hello!"

result2 = get_hello()
print(result2)  # "Hello!" 출력
[문제 6] 정답:

python
# 오류 1: 기본값 없는 c가 기본값 있는 b 뒤에 위치 → 순서 변경
# 오류 2: (사실 오류 1만 수정해도 동작하지만) 의도에 따라 c를 앞으로

def calculate(a, c, b=10):   # c를 b 앞으로 이동
    total = a + b + c
    return total

print(calculate(1, 3, 2))   # a=1, c=3, b=2 → 6
# 또는 기본값 사용
print(calculate(1, 3))      # a=1, c=3, b=10 → 14
📝 해설:

오류 1: def calculate(a, b=10, c) — 기본값이 있는 b=10 뒤에 기본값이 없는 c가 오면 SyntaxError 발생. 파이썬은 어떤 인자가 b이고 어떤 게 c인지 위치로 판단할 수 없기 때문입니다.
수정 원칙: 기본값 없는 매개변수 → 기본값 있는 매개변수 순서를 항상 지켜야 합니다.
python
# ❌ SyntaxError
def f(a=1, b):
    pass

# ✅ 올바른 순서
def f(b, a=1):
    pass
[문제 7] 정답 예시:

python
def describe_number(n):
    if n > 0:
        return "양수입니다"
    elif n < 0:
        return "음수입니다"
    else:
        return "0입니다"

print(describe_number(5))   # 양수입니다
print(describe_number(-3))  # 음수입니다
print(describe_number(0))   # 0입니다
📝 해설:

print() 대신 return을 사용해야 한다는 점이 핵심입니다. return을 쓰면 반환된 값을 다른 변수에 저장하거나 추가 가공이 가능해 활용도가 훨씬 높습니다.
if / elif / else 구조로 세 가지 경우를 모두 처리합니다. else가 없으면 n == 0일 때 아무것도 반환하지 않아 None이 반환되므로 반드시 포함해야 합니다.
다른 풀이: 삼항 연산자(조건 표현식)로도 작성 가능합니다.
python
# 삼항 표현식 활용 (심화)
def describe_number(n):
    return "양수입니다" if n > 0 else ("음수입니다" if n < 0 else "0입니다")
