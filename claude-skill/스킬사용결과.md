## ✅ 정답 및 해설

---

**[문제 1]** 정답: **③**

📝 해설:
- **③이 정답**인 이유: `def` 키워드로 함수를 한 번 정의하면 프로그램 어디서든 여러 번 호출할 수 있는 것이 함수의 핵심 목적입니다.
- **①이 오답**인 이유: `return`문은 선택사항입니다. 없으면 자동으로 `None`을 반환합니다.
- **②이 오답**인 이유: 함수 이름은 변수명 규칙과 동일하게, 숫자로 시작할 수 없습니다. (`my_func` ✅, `1func` ❌)
- **④이 오답**인 이유: 함수 안에서 선언한 변수는 **지역 변수(local variable)** 로, 함수 밖에서는 접근할 수 없습니다.

```python
def my_func():
    local_var = 10  # 지역 변수

my_func()
print(local_var)  # NameError: name 'local_var' is not defined
```

**[문제 2]** 정답: **(a) O / (b) X**

📝 해설:
- **(a) O**: 기본값(default value)이 지정된 매개변수는 호출 시 생략 가능합니다. 생략하면 지정된 기본값이 사용됩니다.
- **(b) X**: 반대입니다. **기본값이 없는 매개변수가 앞에**, 기본값이 있는 매개변수가 뒤에 와야 합니다. 그렇지 않으면 `SyntaxError`가 발생합니다.

```python
# ✅ 올바른 순서: 기본값 없는 것 → 기본값 있는 것
def func(a, b=10):
    pass

# ❌ 잘못된 순서
def func(a=10, b):  # SyntaxError!
    pass
```

**[문제 3]** 정답: **① `def`  /  ② `return`**

📝 해설:
- `def`는 함수를 **정의(define)** 할 때 사용하는 키워드입니다. 반드시 함수 이름 앞에 붙여야 합니다.
- `return`은 함수가 계산한 값을 **호출한 곳으로 돌려보낼 때** 사용합니다. `print()`는 화면에 출력만 할 뿐, 값을 반환하지 않는다는 점과 혼동하지 않도록 주의하세요.

```python
def add(a, b):
    return a + b      # ✅ 값을 반환

def add_wrong(a, b):
    print(a + b)      # ❌ 화면에 출력만 할 뿐, 반환값은 None

result = add(3, 5)
print(result)  # 8

result2 = add_wrong(3, 5)  # 8 출력됨
print(result2)             # None ← 반환값이 없으므로!
```

**[문제 4]** 정답:
```
안녕하세요, 철수!
반가워요, 영희!
잘 지냈어요?, 민준!
```

📝 해설:
- **첫 번째 호출** `greet("철수")`: `name="철수"`, `msg`는 생략되었으므로 기본값 `"안녕하세요"` 사용
- **두 번째 호출** `greet("영희", "반가워요")`: 위치 순서대로 `name="영희"`, `msg="반가워요"` 전달
- **세 번째 호출** `greet(msg="잘 지냈어요?", name="민준")`: **키워드 인자(keyword argument)** 방식으로 전달. 순서와 상관없이 이름으로 매핑되므로 결과는 동일합니다.

```python
# 위치 인자: 순서가 중요
greet("철수", "안녕")     # name="철수", msg="안녕"

# 키워드 인자: 이름으로 지정하므로 순서 자유
greet(msg="안녕", name="철수")  # 동일한 결과
```

**[문제 5]** 정답: **`None`** / 이유: `say_hello()`는 `return`문이 없기 때문에 자동으로 `None`을 반환한다.

📝 해설:
파이썬의 모든 함수는 반드시 값을 반환합니다. `return`문을 명시하지 않으면 파이썬이 자동으로 `return None`을 실행합니다. `print()`는 화면에 출력하는 동작이지, 값을 반환하는 것이 아닙니다. 이 둘을 구분하는 것은 함수 학습에서 가장 중요한 포인트 중 하나입니다.

```python
def say_hello():
    print("Hello!")
    # 내부적으로 return None이 자동 추가됨

result = say_hello()  # "Hello!" 출력
print(result)         # None 출력

# 비교: return이 있는 경우
def get_hello():
    return "Hello!"

result2 = get_hello()
print(result2)  # "Hello!" 출력
```

**[문제 6]** 정답:

```python
# 오류 1: 기본값 없는 c가 기본값 있는 b 뒤에 위치 → 순서 변경
# 오류 2: (사실 오류 1만 수정해도 동작하지만) 의도에 따라 c를 앞으로

def calculate(a, c, b=10):   # c를 b 앞으로 이동
    total = a + b + c
    return total

print(calculate(1, 3, 2))   # a=1, c=3, b=2 → 6
# 또는 기본값 사용
print(calculate(1, 3))      # a=1, c=3, b=10 → 14
```

📝 해설:
- **오류 1**: `def calculate(a, b=10, c)` — 기본값이 있는 `b=10` 뒤에 기본값이 없는 `c`가 오면 `SyntaxError` 발생. 파이썬은 어떤 인자가 `b`이고 어떤 게 `c`인지 위치로 판단할 수 없기 때문입니다.
- **수정 원칙**: 기본값 없는 매개변수 → 기본값 있는 매개변수 순서를 항상 지켜야 합니다.

```python
# ❌ SyntaxError
def f(a=1, b):
    pass

# ✅ 올바른 순서
def f(b, a=1):
    pass
```

**[문제 7]** 정답 예시:

```python
def describe_number(n):
    if n > 0:
        return "양수입니다"
    elif n < 0:
        return "음수입니다"
    else:
        return "0입니다"

print(describe_number(5))   # 양수입니다
print(describe_number(-3))  # 음수입니다
print(describe_number(0))   # 0입니다
```

📝 해설:
- `print()` 대신 `return`을 사용해야 한다는 점이 핵심입니다. `return`을 쓰면 반환된 값을 다른 변수에 저장하거나 추가 가공이 가능해 활용도가 훨씬 높습니다.
- `if / elif / else` 구조로 세 가지 경우를 모두 처리합니다. `else`가 없으면 `n == 0`일 때 아무것도 반환하지 않아 `None`이 반환되므로 반드시 포함해야 합니다.
- 다른 풀이: 삼항 연산자(조건 표현식)로도 작성 가능합니다.

```python
# 삼항 표현식 활용 (심화)
def describe_number(n):
    return "양수입니다" if n > 0 else ("음수입니다" if n < 0 else "0입니다")
```
