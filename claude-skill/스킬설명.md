# 파이썬 튜터링 문제 출제 스킬

## 목적
튜터링 세션에서 튜티가 그날 배운 파이썬 주제를 입력하면, 해당 주제에 맞는 문제 7개를 출제하고 정답 및 해설을 제공한다.

---

## 입력 형식
- 사용자가 주제를 입력한다. 예: `"자료형"`, `"반복문"`, `"함수"`, `"리스트 컴프리헨션"` 등
- 주제는 단어, 짧은 문장, 또는 여러 주제를 동시에 입력할 수 있다.

---

## 출제 규칙

### 문제 구성
| 구분 | 수량 | 설명 |
|------|------|------|
| 기초 개념 문제 | 3문제 | 해당 주제의 핵심 개념 이해를 확인하는 문제 |
| 심화 문제 | 4문제 | 응용력, 문제 해결력, 코드 작성 능력을 요구하는 문제 |
| **합계** | **7문제** | |

### 문제 형식 (다양하게 섞을 것)
아래 형식 중 최소 3가지 이상을 한 세트에 포함시킨다:

1. **개념 사지선다** - 4개의 보기 중 정답을 고르는 문제
2. **코드 빈칸 채우기** - 코드 일부가 `______` 또는 `___[설명]___`으로 비어 있는 문제
3. **단답형** - 짧은 텍스트로 답하는 문제 (한 단어~한 문장)
4. **O/X 문제** - 설명이 맞는지 틀린지 판단
5. **코드 작성형** - 조건에 맞는 코드를 직접 작성하는 문제
6. **코드 결과 예측형** - 주어진 코드의 출력 결과를 예측하는 문제
7. **오류 찾기형** - 버그가 있는 코드에서 오류를 찾고 수정하는 문제

---

## 출력 형식

### 1단계: 문제 출제
아래 형식으로 7문제를 순서대로 출력한다.

```
📘 오늘의 주제: [주제명]

━━━━━━━━━━━━━━━━━━━━━
🟢 기초 개념 문제
━━━━━━━━━━━━━━━━━━━━━

[문제 1] (문제 형식 표시, 예: 사지선다)
문제 내용...

[문제 2] (문제 형식 표시)
문제 내용...

[문제 3] (문제 형식 표시)
문제 내용...

━━━━━━━━━━━━━━━━━━━━━
🔴 심화 문제
━━━━━━━━━━━━━━━━━━━━━

[문제 4] (문제 형식 표시)
문제 내용...

[문제 5] ...
[문제 6] ...
[문제 7] ...

━━━━━━━━━━━━━━━━━━━━━
✅ 정답 및 해설
━━━━━━━━━━━━━━━━━━━━━
(문제 출제 직후 자동으로 이어서 출력)
```

### 2단계: 정답 및 해설
**문제 7개가 모두 출제된 직후, 자동으로 이어서 정답과 해설을 출력한다. 사용자가 따로 요청하지 않아도 반드시 제공해야 한다.**

```
━━━━━━━━━━━━━━━━━━━━━
✅ 정답 및 해설
━━━━━━━━━━━━━━━━━━━━━

[문제 1] 정답: [정답]
📝 해설:
- 핵심 개념을 3~5문장으로 설명
- 왜 이게 정답인지 원리 중심으로 서술
- 오답 보기가 있는 경우, 왜 오답인지도 간략히 설명
- 관련 예시 코드를 반드시 포함 (```python 블록 사용)
- 실수하기 쉬운 포인트나 실전 팁 추가

[문제 2] 정답: [정답]
📝 해설:
(동일한 형식 반복)

... (문제 7까지 동일하게 반복)
```

#### 해설 작성 기준
- 단순히 "정답은 X입니다"로 끝내지 않는다
- **왜 그게 정답인지** 개념 원리를 반드시 설명한다
- 코드 관련 문제는 예시 코드를 항상 포함한다
- 오류 찾기형 문제는 수정 전/후 코드를 모두 보여준다
- 코드 작성형 문제는 모범 답안 코드와 함께 다른 풀이 방법도 있으면 소개한다
- 튜티가 자주 헷갈리는 포인트는 따로 강조해준다

---

## 품질 기준
- 문제는 해당 주제의 핵심 개념을 균형 있게 다룰 것
- 기초 문제는 개념을 처음 배운 튜티도 이해할 수 있는 수준으로 작성
- 심화 문제는 실제 코드를 작성하거나 응용 능력을 요구할 것
- 같은 형식이 연속으로 3개 이상 나오지 않도록 배치
- 코드 블록이 포함되는 문제는 반드시 마크다운 코드 블록(```python ... ```)으로 감쌀 것
- 해설은 단순히 정답만 알려주는 것이 아니라 **왜 그게 정답인지** 원리를 설명할 것

---

## 주제별 예시 커버리지 (참고)
| 주제 | 포함할 개념 예시 |
|------|----------------|
| 자료형 | int, float, str, bool, type(), 형변환 |
| 리스트 | 인덱싱, 슬라이싱, append/remove, 리스트 메서드 |
| 딕셔너리 | key-value, get(), items(), keys(), values() |
| 반복문 | for, while, range(), break, continue |
| 함수 | def, return, 매개변수, 기본값, *args, **kwargs |
| 클래스 | __init__, self, 상속, 메서드 |
| 예외처리 | try-except, finally, raise, 예외 종류 |

주제 테이블에 없는 주제가 입력되어도 동일한 방식으로 문제를 출제한다.
